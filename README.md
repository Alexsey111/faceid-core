# FaceID Core — Стабильный baseline (ветка main)

## 📌 Обзор

Данная ветка содержит **стабильную базовую реализацию** FaceID Core на основе пайплайна `InsightFace FaceAnalysis`.

Это:

* ✅ **Стабильная версия**
* ✅ **Детерминированное поведение**
* ✅ **Все тесты проходят**
* ❗ **Не оптимизирована под нагрузку**

Используется как:

* baseline для сравнения
* эталон корректности
* fallback-реализация

---

## 🧠 Архитектура

### ML pipeline

```
Изображение → Preprocess → FaceAnalysis.detect() → Embedding → Normalize → Verify
```

* Детекция: RetinaFace (через InsightFace)
* Эмбеддинг: ArcFace
* Размер вектора: 512
* Нормализация: L2

---

## ⚙️ Основные характеристики

| Параметр               | Значение                  |
| ---------------------- | ------------------------- |
| Pipeline               | FaceAnalysis (монолитный) |
| Средняя latency        | ~500–800 ms               |
| Пропускная способность | ~1–2 RPS (CPU)            |
| Similarity (same)      | ~0.66+                    |
| Similarity (diff)      | ~0.03–0.1                 |
| Масштабирование        | ❌ Ограничено              |
| Async                  | ❌ Нет                     |
| Batching               | ❌ Нет                     |

## 🔌 API

### `/verify_base64`

Синхронная верификация лица.

#### Запрос

```json
{
  "image": "<base64>"
}
```

#### Ответ

```json
{
  "status": "match | no_match | low_confidence | no_face",
  "similarity": 0.0,
  "liveness_passed": true | false | null,
  "replay_detected": true | false
}
```

## ⚠️ Ограничения

Эта ветка **не предназначена для продакшн-нагрузки**.

### Основные ограничения:

* Однопоточный ML pipeline
* Нет batching
* Нет async обработки
* CPU-bound детекция (RetinaFace)
* Низкий throughput (~1–2 RPS)
