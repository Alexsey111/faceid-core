Кадры используются только в памяти (152-ФЗ): не сохраняются, не логируются.

режим проверки живости

POST /api/v1/verify_base64 — верификация по кадру с камеры.

POST /api/v1/upload_base64 — записать эталон с камеры или файла с ПК.

Файл с ПК читается только в памяти браузера и уходит как base64 (152-ФЗ: исходник на сервере не хранится).

POST /api/v1/liveness (passive, multipart) — отдельная проверка живости.

Активный челлендж (WS): init → стрим кадров с действиями → liveness_token → verify active. Защита от cutout/print.

GET /api/v1/config — текущие пороги сервера (read-only). Слайдер — клиентская интерпретация match/no_match.

ПараметрЗначение

Влияет только на цвет бейджа в результатах верификации. Серверный порог не меняется.
